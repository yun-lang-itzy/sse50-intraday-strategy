# sse50-intraday-strategy

上证50 成分股 Level-2 日内微观结构研究（2026-09-23，单日）。

用上交所 Level-2 的逐笔成交、行情快照和逐笔委托，回答三类问题：

1. 当天的下跌是怎么发生的：时间路径、市场宽度、行业、主动资金。
2. 市场的微观结构：价差、盘口深度、委托规模、挂单存活时间。
3. 盘口因子能否预测短期价格：12 个微观结构因子对未来 3–60 秒中间价变化的 IC，以及岭回归组合的样本外表现。

> 样本只有 **1 个交易日、50 只股票**。描述当天发生了什么的结论可靠；关于"规律"的推断只能当线索，需要更多交易日检验。见文末[局限性](#局限性)。

## 目录

```
src/
  common.py            路径、时间换算、股票简称、申万一级行业、字段编码
  build_datasets.py    原始数据 -> 市场、个股、委托类结果（9 个 JSON）
  factor_research.py   12 个因子、逐股 IC、岭回归组合、分档收益（3 个 JSON）
  summary.py           从结果 JSON 打印本 README 引用的数字
  make_figures.py      从结果 JSON 绘制 figures/ 下的 4 张图
output/                脚本生成的结果，每个文件是行对象数组
figures/               汇总图（下跌的时间结构、因子 IC、挂单存活时间、价差与股价）
dashboard/index.html   交互式仪表板页面源码（见下文说明）
data/                  放原始 parquet（未随仓库提供）
```

## 复现

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# 把 exe_20260923.parquet、snp_20260923.parquet、ord_20260923.parquet 放进 data/
python src/build_datasets.py --data-dir data --out-dir output
python src/factor_research.py --data-dir data --out-dir output
python src/summary.py output
python src/make_figures.py output figures
```

`summary.py` 和 `make_figures.py` 只读 `output/`，不需要原始数据，克隆仓库后可以直接运行。作图默认使用 macOS 自带的中文字体（Hiragino Sans GB），其他系统需要在脚本开头的 `font.family` 里换成本机已有的中文字体。

换一个交易日用 `--date YYYYMMDD`。仓库里的 `output/` 就是用以上命令生成的。

## 数据

原始数据未上传：三个文件合计约 230 MB，逐笔委托单个文件超过 GitHub 的 100 MB 上限，且 Level-2 数据通常有授权限制。脚本期望的字段如下。

| 文件 | 内容 | 记录数 | 关键字段 |
|---|---|---|---|
| `exe_*.parquet` | 逐笔成交 | 379 万 | `BSFlag`（66=B 主动买，83=S 主动卖，0=集合竞价），`BidOrder`/`AskOrder`，`Price`，`Volume`，`Time` |
| `snp_*.parquet` | 行情快照（约 3 秒一张） | 25 万 | 十档 `BidPrice1..10`/`BidVolume1..10`/`Ask*`，`PreClose`，`Open/High/Low`，`AccVolume`，`AccTurnover` |
| `ord_*.parquet` | 逐笔委托 | 628 万 | `OrderKind`（65=A 新增，68=D 撤单，83=状态），`FunctionCode`（66=买，83=卖），`OrderOriNo`，`Volume`，`Time` |

`Time` 为 `HHMMSSmmm` 整数。成交量单位为股，成交额单位为元。

## 口径

- **时段**：连续竞价为 09:30–11:30、13:00–14:57。15:00 之后的盘后固定价格成交不计入。集合竞价成交没有主动方，不计入主动买卖。
- **主动单分档**：把同一主动方委托号的所有成交合并为一笔主动单，按其全天成交额分为小单 <4 万、中单 4–20 万、大单 20–100 万、超大单 ≥100 万元。这是常用口径，不是交易所定义；单笔规模也不等于投资者类型。
- **逐笔委托**：上交所只发布委托中未立即成交、进入盘口的部分，所以撤单率、委托规模、挂单存活时间都只针对挂单。
- **挂单存活时间**：按 `OrderOriNo` 把撤单与它的新增委托配对，扣除 90 分钟午休。
- **行业**：申万一级（2021 版），按公司主营人工归类，见 `src/common.py`。
- **因子研究**：在每张连续竞价快照上计算因子，目标是未来 h 秒（h = 3、6、12、30、60）的中间价变化（bp），跨越午休或收盘竞价的样本剔除。日内切分为训练 09:30–11:30、验证 13:00–14:00、尾段留出 14:00–14:57。IC 为每只股票的 Pearson 相关，再对 50 只等权平均。岭回归组合的因子先按每只股票训练段的均值、标准差标准化并截断在 ±5，正则强度在验证段按 IC 选取。

## 主要发现

数字均可由 `python src/summary.py output` 复现。

### 当天发生了什么

- **普跌**：9 涨 40 跌，等权平均 -0.61%，全天成交 971.9 亿元。
- **下跌贯穿全天**：等权组合 9:30 为 -0.16%，10:30 为 -0.28%，午盘 -0.46%，14:00 为 -0.55%，14:48 最低 -0.62%，收盘 -0.61%，中途没有反弹。市场宽度开盘即为 9 涨 37 跌，午后进一步恶化到约 10 涨 39 跌。
- **卖压均匀**：主动净买入上午 -27.1 亿、下午 -28.4 亿元。超大单累计净卖出从 10:00 的 -4.6 亿匀速扩大到收盘前的 -28.5 亿元，没有集中抛售的时段。
- **大单卖、小单买**：超大单净买入 -28.5 亿、大单 -27.1 亿、中单 -4.4 亿、小单 +4.5 亿元。
- **资金集中在电子行业**：电子 8 只成分股成交 413 亿元，占四成以上，主动净卖出 22.9 亿元。成交额前 5（兆易创新、澜起科技、生益科技、寒武纪、海光信息）占 36.4%。科创板成交占 25.7%，平均跌 0.95%，主板跌 0.57%。
- **成交时段**：开盘后 30 分钟成交占全天 32.3%，收盘前 30 分钟 11.9%，开盘、收盘集合竞价各约 1%。

### 微观结构

- **最小价位约束**：50 只中有 29 只的平均价差不超过 1.1 个最小价位（0.01 元）。低价股 15–25 bp 的价差来自价格水平而不是流动性差，高价股约 1.5 bp。
- **挂单撤得很快，科创板尤甚**：撤单的挂单存活时间中位数主板 44.3 秒、科创板 6.0 秒；10 秒内撤销的比例主板 30.3%、科创板 67.4%。1 秒内撤销的很少（约 1%）。
- **盘口与当天涨跌**：全天平均盘口不平衡与个股涨跌的秩相关为 -0.59，即买盘较厚的股票跌得更多，与限价买单被动承接卖压一致。这是单日 50 只的观察，不应当作规律。

### 因子预测（尾段留出 IC）

| 因子 | 3 秒 | 12 秒 | 60 秒 |
|---|---|---|---|
| 买卖一档量差 | 0.240 | 0.233 | 0.200 |
| 微价偏离 | 0.225 | 0.222 | 0.196 |
| 十档加权量差 | 0.172 | 0.202 | 0.222 |
| 五档盘口量差 | 0.122 | 0.152 | 0.182 |
| 近 5 秒主动买卖压力 | 0.074 | 0.101 | 0.100 |
| 近 5 秒价格动量 | -0.156 | -0.134 | -0.098 |
| 撤单压力、成交量、价差 | ≈0 | ≈0 | ≈0 |
| **12 因子岭回归组合** | **0.245** | **0.246** | **0.237** |

- 盘口量差和微价偏离最强。一档信息衰减快，十档加权量差在更长周期反而更强。
- 价格动量为负，短期中间价有反转。
- 组合在验证段的 IC 为 0.20–0.22，尾段留出 0.24–0.25，样本外没有衰减。
- 组合分五档后，最高档比最低档的未来 30 秒中间价变化只多约 2.2 bp，小于多数股票的买卖价差。作为主动吃单信号难以覆盖成本，更适合用来决定挂单的时机。
- 盘口因子的高 IC 有相当部分是机械的：挂单薄的一侧容易被吃光，中间价随之移动。
- 同样的信号按分钟平均后对下一分钟几乎没有预测力，时间上的平均把即时信息抹掉了。

## 仪表板

`dashboard/index.html` 是交互式仪表板的页面源码，共五页：市场总览、个股透视、委托与流动性、分析结论、因子预测。它运行在 Claude 的 Dashboard 页面类型里，依赖该运行时提供的 `dash` 数据接口和 d3，不能直接用浏览器打开；数据来自 `output/` 下的 JSON。仅作参考，或作为移植到其他前端的起点。

## 局限性

- **单日样本**：所有"关系"类结论（资金流向与涨跌、盘口与涨跌、因子 IC 的稳定性）都需要多日数据检验。训练、验证、留出都在同一天。
- **横截面小**：n=50 时相关系数的标准误约 0.14，中等强度的相关彼此区分不开。19 个行业中多数只有 1–2 只成分股，行业结论不可靠。
- **预测周期只到 60 秒**：尾段留出只有 57 分钟，180 秒、300 秒周期每只股票的不重叠样本只有十几个，因此不计算。
- **不输出岭回归权重**：盘口量差类因子高度共线，各周期选出的正则强度在 1 到 10000 之间跳动，权重不稳定，不能解读为因子重要性。组合只用于检验整体预测力。

有了更多交易日后，值得做的是：资金流向与次日收益的关系，因子 IC 的跨日稳定性（岭回归改为按日滚动训练），以及用逐笔委托和成交重建完整订单簿、研究更短窗口的可预测性。
